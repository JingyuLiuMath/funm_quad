

Randomized Sketching in Quadrature-Based Restarting for Matrix Functions
================================================================================

About
-----

This MATLAB code implements SKETCH-AND-RESTART framework in the computation o $f(A) b$, where $A$ is a square, large and sparse matrix, $f$ is a suitable matrix function and $b$ is a vector.

It is developed based on the [funm_quad]([guettel/funm_quad: Quadrature-based Arnoldi restarts for matrix functions](https://github.com/guettel/funm_quad)) code.

Reproducing the results
---------------

To reproduce the results in our paper, simply run `test_conv_diff`, `test_qcd` and `test_frac_laplacian`.
